# India Product Universe Specification (PP-C)

## 1. Scope
A deterministic product universe covering 50,000+ real products sold in India across 32+ departments.

## 2. Taxonomy Structure
- **L1 (Department):** e.g., Grocery, Electronics, Personal Care.
- **L2 (Category):** e.g., Dairy & Breakfast, Mobiles, Bath & Body.
- **L3 (Subcategory):** e.g., Milk, Smartphones, Soaps.
- **L4 (Product Family):** e.g., Toned Milk, Android Phones, Cream Soaps.

## 3. Product Generation Logic
Products will be generated by expanding Brand + Category + Family + Variant + Package Size.

### Example Expansion:
- **Brand:** Amul
- **Category:** Dairy -> Milk -> Toned Milk
- **Variants:** Fresh, Long Life
- **Sizes:** 200ml, 500ml, 1L
- **Total Products for this branch:** 2 * 3 = 6 products.

## 4. Brand Coverage
Support for 2,000+ brands including:
- **FMCG:** Aavin, Amul, Mother Dairy, Nandini, Britannia, Parle, ITC, HUL, P&G.
- **Electronics:** Apple, Samsung, Xiaomi, HP, Dell, Boat, Noise.
- **Fashion:** Puma, Nike, Adidas, Bata, Levi's.

## 5. Attributes
Each product MUST contain:
- `id`: UUID
- `name`: Canonical Product Name (e.g., "Amul Toned Milk 500ml")
- `slug`: URL-safe slug
- `brand_id`: Link to brands table
- `category_id`: Link to categories table (L2)
- `description`: Marketing description
- `status`: 'ACTIVE'
- `unit`: ml, g, kg, pc, etc.
- `package_size`: Numeric size
- `image_url`: Deterministic placeholder (e.g., `https://assets.vendorhub.in/products/[slug].png`)
- `search_terms`: Array of keywords including regional names (e.g., "paal", "doodh")

## 6. Implementation Strategy
A TypeScript engine in `lib/product-universe/` will generate the SQL migration file to ensure data integrity and complex relationship mapping.
