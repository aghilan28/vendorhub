# Go/No-Go Decision Board

**Purpose:** Evaluate pilot results and decide next step  
**Timing:** After 2-4 weeks of pilot operation  
**Decision Options:** Scale | Continue Pilot | Pause | Pivot  

---

## Decision Framework

### SCALE (Score ≥ 75, No "not_ready" dimensions)
Expand to 50+ sellers, 500+ customers, launch marketing.

### CONTINUE PILOT (Score 60-74, ≤1 "not_ready")
Address top issues, add more sellers/customers, run 2 more weeks.

### PAUSE (Score 40-59)
Stop onboarding. Investigate root causes. Fix critical issues before resuming.

### PIVOT (Score < 40)
Fundamental market-product fit issue. Redefine approach.

---

## Evaluation Dimensions

| Dimension | Weight | Criteria for "Ready" |
|-----------|--------|---------------------|
| Technology | 15% | Build clean, no critical bugs, <1% error rate |
| Operations | 15% | >80% SLA compliance, tickets resolved |
| Marketplace | 15% | ≥5 active sellers, ≥10 active customers |
| Growth | 10% | Positive week-over-week growth |
| Intelligence | 10% | Engines producing useful recommendations |
| Economics | 15% | Revenue > 0, positive unit economics signal |
| Customer Experience | 10% | ≥3.5/5 satisfaction |
| Seller Experience | 10% | ≥3.5/5 satisfaction |

## Evidence Required for Each Decision

### To SCALE:
- [ ] 10+ active sellers with 90%+ fulfillment
- [ ] 30+ active customers with 3.5+/5 satisfaction
- [ ] 20+ orders per week with positive trend
- [ ] <10% cancellation rate
- [ ] Positive unit economics signal
- [ ] Operations SLA compliance >80%
- [ ] No unresolved critical issues

### To CONTINUE:
- [ ] 5+ active sellers
- [ ] 10+ active customers
- [ ] Clear improvement plan for weak areas
- [ ] No systemic unfixable issues

### To PAUSE:
- [ ] Identified root cause of poor performance
- [ ] Clear remediation plan with timeline
- [ ] Resources allocated to fix

### To PIVOT:
- [ ] Evidence that current approach has fundamental flaw
- [ ] Alternative hypothesis identified
- [ ] Resources and timeline for pivot
