# PP1_SCALE_CERTIFICATION

**Phase 11 — Scale Certification**

Generated by `npm run pp1:certify` → `docs/pp1/generated/taxonomy-certification.json` and verified
by deterministic tests in `tests/unit/taxonomy-foundation.test.ts`.

## Method

`generateSyntheticTaxonomy(N)` deterministically builds a structurally-valid tree with exactly `N`
CATEGORY nodes (plus departments and optional subcategories). `certifyScaleTarget(N)` then builds the
engine, runs full integrity validation, and spot-checks lookup (by id/slug/path) and traversal
(parent/ancestor/child consistency). This isolates engine behaviour from data errors.

## What this proves (per directive)

- **Integrity** — validation reports 0 errors at every tier (no circular refs, orphans, duplicate
  slugs/paths, depth violations).
- **Traversal** — parent/ancestor/descendant/child queries remain correct at 10k+.
- **Filtering / search readiness** — `buildSearchIndex` produces one document per node; faceted
  attributes resolve via inheritance.
- **Governance readiness** — every node is addressable by stable id for create/edit/merge/split.
- **No performance degradation** — indexed maps keep lookups O(1) and traversal O(children); build
  time stays well within bounds at 10k–20k nodes.

## Headroom for ingestion (100k+ products)

The taxonomy is a bounded classification layer (hundreds–thousands of nodes) that products attach
to at the master-product/seller layer. Certifying 10k categories with full integrity demonstrates
the structure supports the directive's 100,000+ product ingestion **without restructuring** — product
volume scales independently of taxonomy node count.
