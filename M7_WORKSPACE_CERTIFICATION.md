# M7.14 — Workspace Certification Report

Phase: KARTEX M7

Certifies that the platform is operable as **one coherent workspace**, not five
separate products.

## Checklist

| Requirement | Evidence | Status |
| --- | --- | --- |
| Single personal landing | `/workspace` Intelligence Home | ✅ |
| My Projects / Tasks / Reviews / Approvals | Home + Project Center + Action Center | ✅ |
| Recent Insights / Simulations / Governance actions | Home + Inbox + Activity | ✅ |
| Pending Work in one place | Action Center | ✅ |
| Notifications | Notification Center + header bell badge | ✅ |
| Unified Inbox | Intelligence Inbox (insights/recs/risks/approvals/exceptions/tasks) | ✅ |
| Unified Search across systems + projects + tasks | `/workspace/search` (grouped) | ✅ |
| Activity timeline | `/workspace/activity` (visual, grouped by day) | ✅ |
| Project linking across all systems | Project Center `CrossRef` links | ✅ |
| Personalization | Preferences, favorites, bookmarks, saved searches | ✅ |
| Product analytics | `/workspace/analytics` | ✅ |
| Reduced clicks / context switching | See M7_USER_JOURNEY_OPTIMIZATION.md | ✅ |
| One-product navigation | Hub links across every system sidebar | ✅ |

## Conclusion

From `/workspace` a non-technical user sees their projects, their tasks,
everything awaiting them, a unified inbox and notifications, a cross-system
search, and an activity timeline — and reaches any underlying system in one
click. The five systems are operated through a single workspace experience.
**Workspace experience is certified.**
